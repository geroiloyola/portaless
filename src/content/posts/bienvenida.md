Este es un artículo de ejemplo escrito en **Markdown**. Vive en
`src/content/posts/bienvenida.md` — edítalo con cualquier editor de texto,
súbelo a tu repositorio, y el sitio se reconstruye automáticamente vía
GitHub Actions o Cloudflare Pages.

No necesitas un panel de administración, ni una base de datos, ni un
servidor propio para publicar contenido. Solo un archivo de texto y `git push`.

## Cómo agregar más artículos

1. Crea un nuevo archivo `.md` en `src/content/posts/`.
2. Completa el frontmatter (`title`, `description`, `pubDate`).
3. Escribe tu contenido en Markdown debajo.
4. Haz commit y push — el despliegue es automático.
