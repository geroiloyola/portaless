# Infraestructura como Código (opcional)

Directorio reservado para definiciones de Terraform que automaticen la
configuración de dominios, registros DNS (incluyendo los futuros
registros de Protocol APW) y proyectos de Cloudflare Pages.

**Estado actual: vacío.** Ningún archivo `.tf` implementado todavía en
este MVP — se agrega la carpeta para respetar la estructura propuesta y
dejar el punto de extensión listo para cuando el proyecto lo necesite.
