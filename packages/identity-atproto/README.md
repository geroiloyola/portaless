# @portaless/identity-atproto

Identidad AT Protocol (sintaxis de handles, resolucion handle <-> DID
bidireccional, clave de firma y PDS) y puente OPCIONAL de reputacion con
APW (`did:apw`): el join de reputacion para un handle AT con la
reputacion del sitio (W) y del usuario (R).

Implementado en v0.0.9.10 — dejo de ser un stub. Ver
`docs/architecture/identity-atproto.md` en la raiz del repo (estado real,
limites honestos y lo que sigue sin implementar: PDS propio, Lexicons de
comentarios, App View).
