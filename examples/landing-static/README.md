# Ejemplo: Landing Page Estática

Configuración de referencia para una landing page de una sola página,
construida enteramente con Atomic Elements (`packages/atomic-elements/`),
sin colección de blog ni comercio.

Recomendado: una sola entrada en `src/content/pages/` (ver el ejemplo
`ejemplo-atomic-elements.json`), desplegada directamente en GitHub Pages
o Cloudflare Pages sin necesidad del dashboard administrativo completo.
