# Notas de diseño: Protocol APW (no implementado en este MVP)

Este MVP despliega Portaless usando hosting delegado tradicional
(GitHub Pages / Cloudflare Pages) con configuración DNS manual estándar.

El Protocol APW completo —capa de control vía DNS (DNSLink + did:web),
verificación de integridad por hash publicado en TXT, y portabilidad total
del host de entrega— está documentado por separado y se irá integrando en
versiones futuras de Portaless una vez validado el producto base con sitios
reales en producción.

Ver el documento "Protocol APW (Air Portal Websites)" del proyecto para el
diseño completo.
