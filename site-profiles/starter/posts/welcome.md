# Welcome to your Portaless site

This is the default starter post for a clean Portaless installation.

## How to edit and publish

- **Static editing (Git / Markdown):** Edit this file in `site-profiles/starter/posts/welcome.md` or add new `.md` files in the same directory. Edit your home layout in `site-profiles/starter/home.json`.
- **Self-hosted node (optional):** If you run Portaless as a self-hosted Node or Docker service, you can also edit pages visually from `/admin/` or connect an MCP client, review drafts, and publish approved snapshots. Static hosts like GitHub Pages serve only the compiled HTML output (no admin panel runtime).
- **Site profiles:** By default, builds use `PORTALESS_SITE_PROFILE=starter`. To build the full fictional showcase and documentation site instead, set `PORTALESS_SITE_PROFILE=demo`.
