## Experimental / limitaciones conocidas

- **ML-DSA es EXPERIMENTAL.** `@noble/post-quantum` no tiene auditoria
  independiente (lo declara su propio README). El formato JWK `AKP` viene
  de un borrador IETF y puede cambiar. No se valido contra ningun agente
  externo real.
- **Sin test de punta a punta ML-DSA.** Los tests prueban el verificador
  aislado, no un request HTTP firmado armado por `web-bot-auth` (^0.1.0).
  Se decidio no agregar una segunda dependencia solo para simular al
  agente firmante. Cierra cuando exista un agente real que publique un JWK
  `AKP`.
- `packages/trust-layer/src/webbotauth/verify.ts` (el que usa
  `functions/_middleware.js`) sigue siendo solo Ed25519.
- Verificacion reforzada por email: pendiente, no hay backend de
  `email:send`.
- Las paginas `.astro` nuevas no tienen tests automaticos (falta
  Playwright).
